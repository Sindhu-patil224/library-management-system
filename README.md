# Library Management System

This project is a simple Library Management System built using Spring Boot, MySQL, and Thymeleaf.  
It allows users to manage books through a web interface.

## Features
- Add new books
- View all books
- Issue books
- Return books

## Technologies Used
- Java
- Spring Boot
- MySQL
- Thymeleaf
- HTML & CSS
